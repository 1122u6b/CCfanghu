## 仍未证明

这不是完整成品验收。还未证明：服务安装和敏感操作的端到端使用、完整 TUN 自动路由/私有 DNS、浏览器 WebRTC/全应用泄露、休眠恢复、生产安装器交互、域名反代、香港服务器部署及商业容量。部分原版业务功能仍待补齐。

已检查官方上游源码：Windows 内核依赖的 `sing-tun v0.4.28` 通过 `go:embed` 包含 amd64 Wintun 0.14.1 DLL，因此不应从非官方站点另行下载驱动；此源码检查本身不等同于驱动已在 Windows 实际启动。
